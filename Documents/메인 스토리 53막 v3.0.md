## 1. 최신 핵심 세계관

### 1.1 마왕의 정체

전설에서 말하는 '마왕'의 이름은 모르스다.
그러나 현재 인류가 알고 있는 마왕의 역사는 미르엘이 오랜 세월에 걸쳐 개변한 역사다.
모르스는 원래 마족과 인간 모두를 다스리려 했던 성군에 가까운 존재였으며, 인간의 이기심과 종족 차별 속에서 봉인됐다.
모르스의 정신은 하나의 완전한 인격으로 남아 있지 않고 희·노·애·락의 네 감정/인격 파편으로 분리된 상태다.

**희 — 기쁨**
- 울토르 마법학교 지하의 숨겨진 마법진에 봉인
- '마왕은 학교에 잠들어 있다'는 오래된 금기의 실체와 연결
- 마지막에 모르스가 완전체가 되기 위해 반드시 회수

**노 — 분노**
- 버려진 신전 내부에 봉인
- 미르엘이 역사 개변을 조사하는 주인공 일행을 위험하다고 판단한 뒤 봉인된 '노'의 인격을 해방
- 화염 마족 루스벨에게 주입해 폭주
- 루스벨 = 폐허된 신전 편 최종보스이자 '노'의 숙주

**애 — 슬픔**
- 화산지대에서 살아가는 모르스에게 남아 있는 핵심 인격
- 모르스가 현재까지 자신의 성향과 기억 일부를 유지할 수 있게 만든 감정
- 최종적으로 다른 세 감정을 다시 흡수하면서 모르스가 완전체가 됨

**락 — 즐거움**
- 미르엘이 모르스에게서 흡수해 자신의 힘으로 사용
- 미르엘의 능력과 역사 개변의 근원이 되는 핵심 조각
- 최종전에서 미르엘을 쓰러뜨린 뒤 모르스가 회수

## 2. 미르엘의 최신 설정

### 2.1 정체

미르엘은 인마대전 당시부터 존재해 온 초월적 존재다.
현재는 울토르 마법학교의 교수이자 교장으로 활동한다.
학교의 교육과 역사 연구를 총괄하면서 학생들과 교직원에게 신뢰받는 얼굴을 유지하지만, 최종적으로는 모든 역사 개변 사건의 흑막임이 드러난다.
정확한 장수 방식이나 불멸의 원리는 4학년 후반에 공개할 추가 설정 대상으로 남기되, 이야기상 '500년 전부터 같은 미르엘이 존재했다'는 사실 자체는 확정한다.

### 2.2 역사 개변의 목적

미르엘은 단순히 세상을 정복하려는 악당이 아니다.
그녀는:
- 모르스의 품위와 성군으로서의 자질을 질투함
- 자신보다 고상한 모르스의 존재를 불쾌하게 여김
- 마족과 다양한 인외종을 미적으로 혐오하고 열등하게 여김
- 인간들이 아무것도 모른 채 마족을 증오하는 모습을 즐김
- 500년 가까운 세월의 지루함에서 벗어나기 위해 역사 자체를 장난감처럼 다룸

이라는 뒤틀린 동기를 가진다.
즉 현재의 인마대전 역사, 마족에 대한 인간의 적대감, 마물/인외종이 화산지대로 밀려난 사회구조는 미르엘이 의도적으로 만든 세계의 결과다.

## 3. 루스벨 최신 설정

- 루스벨은 화염 속성 NPC이며 마법학교 인물이다(기존 화염 여성 동료 캐릭터 그대로).
- 버려진 신전에서 미르엘이 '노'의 인격 봉인을 풀어 루스벨에게 주입한다.
- 그 결과 루스벨은 폭주하고, 폐허된 신전 편의 최종보스가 된다.
- 폭주 후 루스벨은 처치되지 않고 살아남아 도망친다.
- 그가 방출한 강한 화염의 영향으로 설원 지역의 기후가 비정상적으로 따뜻해진다.
- 이후 루스벨은 설원 깊은 동굴에 은신한다.
- 주인공 일행이 루스벨을 발견할 수 있느냐가 최종 엔딩 루트의 첫 번째 핵심 분기점이다.

## 4. 지역/장 구조

```text
CH0  울토르 마법학교 / 입학
  ↓
CH1  에르디아 숲
  ↓
CH2  에르디아 해안 / 아틀란티스
  ↓
CH3  스톰헤이븐 / 천공 신전
  ↓
CH4  버려진 폐허 / 버려진 신전
  ↓
CH5  설원 / 오로라 마을
  ↓
CH6  화산지대 / 마물 마을 / 모르스의 성
  ↓
CH7  최종장 / 울토르 학교 → 스톰헤이븐(국왕 알현) → 모르스와 새로운 시대
```

주의:
- CH2와 CH3은 별개의 지역/스토리 장이다.
- CH3 스톰헤이븐은 하늘/천공신전 쪽이다.
- CH4 폐허는 언데드/폐허/버려진 신전 쪽이다.
- CH6의 모르스는 필드에서 아무 때나 싸우는 보스가 아니다.
- 모르스와의 전투는 엔딩 조건에 따른 최종장 전투로만 발생한다.

## 5. 평판 시스템 — 최종 엔딩의 필수 장치

최종적으로 인간 사회와 마족 사회의 오해를 풀기 위해 주인공의 인망이 증거와 신뢰를 대신하는 장치가 필요하다.

### 5.1 평판 대상 6개 거점
- 안전지대 마을
- 아틀란티스 마을
- 천공 신전 성역
- 폐허 신전 쪽 마을
- 오로라 마을
- 마물 마을

### 5.2 평판 획득

각 거점의 분수대를 핵심 허브 오브젝트로 사용한다.
분수대에서:
- 주민 서브퀘스트 수령
- 지역 채집 요청
- 지정 에픽 몬스터 사냥
- 마을 문제 해결
- 생활/제작품 납품
- 낚시/사냥/연금술 성과 제출
- 특정 NPC 지원

등을 통해 평판을 올린다.

### 5.3 평판 레벨

```text
Lv.1 낯선 사람
Lv.2 얼굴을 아는 손님
Lv.3 믿을 만한 모험가
Lv.4 마을의 은인
Lv.5 마을의 대변자
```

### 5.4 Lv.5 보상

거점별로 다음 중 일부/전체를 지급한다.
- 대량의 골드
- 희귀 방어구, 희귀 무기
- 희귀 액세서리
- 지역 특수 소비품
- 마을 상징 아이템(Emblem)

엔딩 조건

```text
RUSPELL_FOUND = true
AND
VOLCANO_REPUTATION_LV5 = true
```

이면 모르스와의 최초 대화에서 협력 루트가 열릴 수 있다.
최종적으로:

```text
ALL_6_VILLAGE_EMBLEMS = true
```

이면 왕 앞에서 인간/비인간 사회의 통합을 증명하는 C 엔딩이 가능하다.
하나라도 부족하면 B 엔딩으로 내려간다.

## 6. 엔딩 구조

### A 엔딩 — '기록된 역사'

```text

```

또는 루스벨을 찾았지만 결정적인 신뢰 조건을 충족하지 못함(마물 마을 상징 없을 시)

※ 구현에서는 `RUSPELL_FOUND`를 실제 키로 쓸 경우 이름을 반드시 `RUSPELL_FOUND` 하나로 통일한다.
권장 실제 키는 `RUSPELL_FOUND` 또는 `RUSPELL_FOUND` 중 하나만 선택한다.

내용:
- 미르엘과 함께 모르스 토벌을 진행
- 설원에서 결정적인 고대문자를 해독하지 못함
- 모르스를 인간의 적으로 오해한 상태가 유지됨
- 모르스 역시 인간들에게 또다시 배신당했다고 판단
- 최종적으로 모르스 토벌
- 미르엘의 역사 개변은 드러나지 않거나 불완전하게 남음
- 학교와 인간 사회는 기존 역사를 사실로 믿음
- 주인공은 승리했지만 플레이어만 찝찝한 진실의 흔적을 보게 됨

톤:
> 승리했지만 세상을 구한 것이 맞는지 의심하게 되는 엔딩

### B 엔딩 — '도망자들'

조건:

```text

AND
ALL_6_VILLAGE_EMBLEMS = false
```

내용:
- 루스벨을 통해 모르스의 '노' 인격에 대한 진실 확인

- 루스벨의 번역을 통해 고대문자 해독 가능
- 모르스가 성군이었다는 진실 확인
- 미르엘에게 역사 개변 책임을 추궁
- 모르스와 협력하여 미르엘을 막을 수 있음
- 그러나 모든 마을 상징이 없어 인간 사회가 모르스를 받아들이지 못함
- 진실은 밝혀졌지만 모르스는 여전히 '마왕'으로 취급됨
- 주인공 역시 모르스의 공범/배신자로 취급받음
- 결국 둘은 인간 사회에서 도피하는 길을 선택

톤:
> 진실은 찾았지만 세상을 설득하지 못한 비극적 해피 엔딩

### C 엔딩 — '새로운 시대'

조건:

```text
RUSPELL_FOUND = true
AND
ALL_6_VILLAGE_EMBLEMS = true
```

내용:
- 여섯 거점의 상징이 주인공의 인망과 증거가 됨
- 모르스가 마물 마을과 인간 사회 앞에서 힘을 합치는 것을 허용
- 주인공이 인간 사회에 모르스의 입장을 대변
- 울토르의 기록과 마을 증언을 기반으로 인마대전 역사의 개변이 폭로됨
- 학교 지하의 '희', 미르엘의 '락', 루스벨의 '노', 모르스의 '애'가 재결합
- 모르스가 완전체가 됨
- 모르스와 주인공이 미르엘을 최종 토벌
- 인간과 마족의 공식 교류 재개
- 마족 마을에 대한 단절 정책 폐기
- 왕 앞에서 과거의 잘못을 인정하고 새로운 교류 체계 수립
- 주인공은 갈등을 끝낸 대변인/영웅으로 인정받음

## 10. 스토리 진행과 주간 퀘스트의 연결

매주 플레이는 다음 구조를 기본으로 한다.

```text
[필수]
수업 참석 / 수업 실습 / 수업 과제
+
[랜덤]
사이트·필드 퀘스트 2개
=
한 주 종료
```

3주 안팎의 주간 진행이 누적되면 메인 스토리 에피소드가 발생한다.
메인스토리에서 요구하는 행동은 가능한 한 외부 퀘스트와 중복되도록 설계한다.
예:

```text
메인: 설원 주민들의 피해 조사
랜덤퀘스트: 오로라 마을 주민 심부름
랜덤퀘스트: 설원 희귀 약초 6개 채집
```

처럼 하나의 모험이 여러 시스템을 동시에 진전시키도록 한다.

## 11. 4학년 2학기 특수 루프

4학년 2학기부터는 졸업까지 남은 시간이 짧기 때문에 일반 주간 퀘스트보다 엔딩 조건 달성을 우선한다.

```text
↓

↓

↓

↓

↓
졸업식
```

## 12. 엔딩이 플레이어의 4년을 평가하도록 하는 기준

최종 엔딩 판정은 단순한 마지막 선택 버튼 하나로 처리하지 않는다.
아래 누적 데이터를 확인한다.

```text
학점/출석
NPC 관계
지역 평판
생활 활동 기록
도감
제작 활동
마을 상징
루스벨 발견 여부
역사 개변 조사 진척
모르스 진실 이해도
```

특히 C 엔딩에서는 마을 상징 6개가 주인공의 '증명' 역할을 해야 한다.
따라서 엔딩에서 마을 사람들이 전부 주인공을 따라 나서는 장면은 단순 호감도 수치가 아니라 실제 플레이 기록에 의해 결정된다.

## 13. 구현용 `web/lib/story.ts` 적용 원칙

현재 `story.ts`의 StoryBeat 구조를 유지하면서 각 에피소드에 다음 메타데이터를 붙이는 것을 권장한다.

```ts
interface MainStoryEpisode {
  id: string
  episodeNo: number
  arcId: string
  title: string
  globalWeek: number
  trigger: 'WEEK_END' | 'FLAG' | 'VISIT' | 'QUEST_CLAIMED'
  requiredFlags?: string[]
  setFlags?: string[]
  mainQuestId?: string
  regionId?: string
  seasonRole?: 'semester' | 'summer' | 'winter' | 'final'
  route?: 'ALL' | 'A' | 'B' | 'C' | 'B_OR_C'
  summary: string
  dialogueSetId?: string
  cutsceneSetId?: string
}
```

중요: 현재 `story.ts`의 기존 대사(lines)는 이번 작업에서 한꺼번에 교체하지 않는다.
이번 단계에서는 제목 / 주차 / 지역 / 필수 플래그 / 신규 플래그 / 메인 퀘스트 연결 / 엔딩 분기 / 요약만 먼저 확정한다.
대사집과 컷신은 다음 작업에서 별도 데이터셋으로 분리한다.

```text

```

## 16. 반드시 지켜야 하는 세계관 체크리스트

- 해안과 스톰헤이븐을 합치지 않는다.
- 모르스는 필드에서 랜덤으로 싸울 수 없다.
- 모르스는 처음부터 악당이 아니다.
- 미르엘이 현재 역사 개변의 핵심 원인이다.
- 미르엘은 단순 교사가 아니라 최종 흑막이다.
- 루스벨은 '노' 인격을 가진 폐허 편 최종보스다.
- 루스벨은 폐허에서 사망하지 않고 설원으로 도망친다.
- 설원의 고대 석비는 유실문자라 처음에는 읽지 못한다.
- 루스벨을 찾으면 모르스의 기억 일부를 해석할 수 있게 된다.
- '희'는 울토르 학교 지하에 봉인돼 있다.
- '락'은 미르엘에게 빼앗겨 있다.
- '노'는 루스벨에게 들어가 있다가 최종적으로 회수된다.
- '애'는 모르스가 가진 감정이다.
- 네 감정이 합쳐져야 모르스가 완전체가 된다.
- C 엔딩에는 6개 거점 상징이 모두 필요하다.
- B 엔딩은 진실을 알아도 사회적 신뢰가 부족할 때 발생한다.
- A 엔딩은 기존 역사와 미르엘의 거짓을 충분히 깨뜨리지 못한 상태에서 모르스를 토벌하는 엔딩이다.
- 본편 최종 결말은 4학년 2학기에 발생한다.
- 4학년 겨울은 본편 이후 졸업식/후일담/자유생활 콘텐츠로 남긴다.
