# 울토르 4년제 학사 · 생활 · 동료 시스템 — 기초 구현 가이드

> 2026-09-28 기초 단계 구현. 스토리 라인은 미확정이라 **시스템(그릇)만** 들어가 있고,
> 스토리·대사·합류 조건은 아래 데이터 파일만 고치면 코드 수정 없이 게임에 반영된다.

## 0. 지역 정리 (PRD 원문과 다른 점)

PRD의 "스톰헤이븐 해"는 실제 게임 맵 구조에 맞춰 나눴다.

| PRD 표기 | 게임 지역(RegionId) | 포함 맵 |
|---|---|---|
| 에르디아 숲 | `ERDIA` | 에르디아 숲 · 이끼 동굴 · 안개 늪지 · 폐광산 |
| 스톰헤이븐 해 (항구·수중·해파리 여왕·심해 암초왕) | `COAST` 바다 해안 · 아틀란티스 | 바다 해안 · 심해 · 아틀란티스 마을 · 대성당 내부 |
| 하늘 유적 (하늘 쪽) | `STORMHAVEN` | 스톰헤이븐(하늘 도시) · 천공 신전 · 대신전 내부 |
| 하늘 유적 (언데드·석상 쪽) | `RUINS` | 버려진 폐허 · 묘지 · 버려진 신전 · 신전 내부 |
| 설원 | `SNOWFIELD` | 루미나 설원 · 오로라 마을 · 성소 내부 |
| 화산지대 | `VOLCANO` | 화산지대 · 마물 마을 · 화산 성채 내부 |
| 모르스 | `MORS` | 모르스의 성 |

→ 2장 = 해안권(COAST), 3장 = 스톰헤이븐 + 버려진 폐허. (`web/lib/regions.ts`, `web/lib/story.ts`)

### 야생 전투맵 구조 (2026-09-28 개편)
지역마다 **기본맵 3단계(난이도순) → 3단계 갈림길에서 특수맵 2개 + 지역 마을**.

| 지역 | 기본 1 → 2 → 3(갈림길) | 특수맵 | 마을 |
|---|---|---|---|
| 에르디아 | 에르디아 숲 → 깊은 숲 → 고목숲 | 이끼 동굴 · 안개 늪지 | (없음 — 마을 귀환 마법진) |
| 해안 | 바다 해안 → 산호 여울 → 암초 해안 | 심해 · 해식 동굴(신규) | 아틀란티스 |
| 스톰헤이븐 | 스톰헤이븐 → 폭풍 구름다리 → 뇌운 고원 | 구름 협곡 · 뇌운 첨탑(신규) | 천공 신전 |
| 폐허 | 버려진 폐허 → 무너진 성곽 → 망각의 광장 | 버려진 묘지 · 지하 납골당(신규) | 버려진 신전 |
| 설원 | 루미나 설원 → 눈보라 언덕 → 서리 침엽수림 | 얼음 동굴 · 얼어붙은 호수(신규) | 오로라 마을 |
| 화산 | 화산지대 → 잿빛 협곡 → 용암 평원 | 폐광산(이끼 동굴에서 이동) · 용암 동굴(신규) | 마물 마을 (+ 모르스의 성) |

- 크기: 기본맵 38×32, 특수맵 28×22 (이전 대비 면적 약 2.5배)
- 구성표: `web/lib/field-specs.ts` (포탈 방향·몬스터 풀·권장 레벨), 생성기: `web/lib/field-maps.ts` (테마별 타일·소품·길)
- 포탈 변(동서남북)·위치를 바꾸거나 맵을 추가하려면 구성표 한 줄만 고치면 길·입구·귀환 위치가 자동으로 맞춰진다.

## 2. 스토리 붙이는 법

### 스토리 비트(사건 1개) 추가 — `story.ts` 의 `STORY_BEATS`
```ts
{
  id: 'Y1W08_THORN_MOTHER',          // 고유 id — 한 번 재생되면 다시 안 나온다
  arcId: 'CH1_ERDIA',
  title: '가시어미 발견',
  trigger: { type: 'WEEK_START', week: 8 },   // WEEK_START | WEEK_END | QUEST_CLAIMED | VISIT | FLAG
  requiredFlags: ['CH1_STARTED'],
  setFlags: ['FOREST_ANOMALY_FOUND'],          // 재생 즉시 켜짐 → 다음 비트의 조건으로
  lines: [
    { speaker: '', text: '나레이션' },
    { speaker: '미르엘 교수', portraitId: 'npc-job-trainer', text: '대사' },
  ],
},
```
- `globalWeek` 계산: `globalWeekOf(학년, 'semester1'|'summer'|'semester2'|'winter', 주차)` (1학년 1학기 1주 = 1, 4학년 겨울 12주 = 192)
- 트리거 `VISIT` 은 맵 첫 진입, `QUEST_CLAIMED` 는 특정 퀘스트 보상 수령 시

### 주차별 필수 퀘스트 — `story.ts` 의 `MAIN_QUEST_BY_WEEK`
```ts
export const MAIN_QUEST_BY_WEEK: Record<number, string> = {
  8: 'MAIN_Y1W08_THORN',   // quests.ts 에 category:'MAIN' 템플릿으로 정의
}
```
비어 있는 주는 기본 일과(학기: 미르엘 교수에게 보고 / 방학: 전투 3회)로 채워진다.

### 동료 합류 조건 — `companions.ts`
`joinYear`(학년) + `joinFlag`(스토리 플래그). 카엘(`COMP_KAEL_JOIN`), 미르엘 교수(`COMP_MIREL_JOIN`)는
플래그를 켜야 합류 가능 → 스토리 비트의 `setFlags` 에 넣으면 된다.

## 3. 주간 진행 규칙
- 매주 필수(MAIN) 1개 + 랜덤 4개(학기: 수업·전투·생활·자유 / 방학: 전투·생활·자유·생활)
- **필수 + 선택 2개 보상 수령** → 학사 수첩에서 "다음 주로"
- 같은 세이브에서 같은 주는 항상 같은 퀘스트(시드 = 플레이어 시드 + 주차 + 장 지역 + 플래그 수)
- 아직 스토리상 도달 전인 지역의 퀘스트는 안 나온다. 학기엔 학교, 방학엔 원정 지역 퀘스트 비중이 커진다.
- 학기 12주차 마감 시 과목 점수 → 성적(A+~F) → 학점

## 4. 생활 시스템 해금 (PRD §29)
| 활동 | 해금 |
|---|---|
| 채집 | 1학년 1학기 |
| 기본 제작(장비) | 1학년 2학기 |
| 낚시 | 1학년 겨울방학 (낚싯대: 상점가 만물상 토비) |
| 연금술 · 요리 | 2학년 1학기 (연금술 가마 / 공동 식당 주방) |
| 사냥(부산물) | 2학년 2학기 |
| 가구 제작 | 3학년 1학기 |
| 마도구 · 코스튬 제작 | 3학년 2학기 |

⚠ 기존에 1학년 1학기부터 쓰던 장비 제작도 PRD대로 1학년 2학기 해금이 됐다.
관리자 패널(/admin) → 학사 탭 → "생활 시스템 전체 해금"으로 테스트 가능(테스트 모드와는 별개).

## 5. 레벨 상한 100
- 전직: 견습 1 → 수습 20 → 정마도사 40 → 상급 60 → 대현자 80
- 계통 스킬 10레벨마다 1개(1·10·20·…·90), 5차 극의 스킬 3종 신설(시간의 불꽃 / 공간 붕괴 / 죽음의 장막, Lv.90)
- 스탯·몬스터 수치는 레벨 50 시절 밸런스 그대로 두고 레벨 축만 2배(`constants.ts legacyLevel/toLevel100`).
  몬스터·지역 권장 레벨도 `2×기존−1` 로 환산. 1→100 총 경험치는 기존 1→50 과 거의 같다.
- 펫도 이제 전투 경험치로 레벨이 오른다.
